Experiments conducted based on the paper: Efficient Interactive LLM Serving with Proxy Model-based Sequence Length Prediction

Paper Summary: a speculative shortest-job-first (SSJF) scheduler that uses a light proxy model (i.e., a fine-tuned BERT-base model) to predict LLM output sequence lengths.

For implementation details, refer to https://github.com/James-QiuHaoran/LLM-serving-with-proxy-models.
